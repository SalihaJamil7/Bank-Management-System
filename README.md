# Bank Management System

A simple **Bank Management System** developed in Python.
This project allows users to manage bank accounts and perform basic banking operations through a menu-driven program.

## Features

* Create a new bank account
* Deposit money
* Withdraw money
* Check account balance
* Transfer money between accounts
* View all accounts
* Delete an account
* Exit the program

## Technologies Used

* Python
* Dictionaries
* Functions
* Loops
* Conditional Statements
* User Input

## How to Run

1. Download or clone this repository.
2. Open the project in Python or VS Code.
3. Run the Python file.
4. Select an option from the menu to perform banking operations.

This project was created to practice **Python programming fundamentals**, including functions, dictionaries, loops, conditional statements, and user input handling.
